# Personal Finance Tracker

## 1. Project Overview

The Personal Finance Tracker is a web-based financial management system designed to help users monitor their personal income, expenses, spending categories, and overall financial activity.

The system combines a traditional CRUD-based financial management application with data analysis features. Users can record their transactions while the system processes the collected data to generate reports, charts, and financial insights.

## 2. Project Goal

The main goal is to create a system that allows users to:

* Manage personal financial records
* Monitor income and expenses
* Categorize transactions
* Understand spending patterns
* View financial reports
* Analyze financial activity using data
* Export financial records for external use

## 3. Target Users

The primary users are individuals who want to manage and understand their personal finances.

The system can also serve as a learning project for demonstrating:

* Full-stack development
* Database management
* SQL
* REST APIs
* Data analysis
* Data visualization
* CRUD operations
* Authentication

## 4. Core Features

### User Authentication

Users can:

* Register an account
* Log in
* Log out
* Access only their own financial records

### Income Management

Users can:

* Add income
* View income
* Edit income
* Delete income
* Categorize income

### Expense Management

Users can:

* Add expenses
* View expenses
* Edit expenses
* Delete expenses
* Categorize expenses

### Categories

Transactions can be organized into categories such as:

* Food
* Transportation
* Bills
* Shopping
* Education
* Entertainment
* Salary
* Allowance
* Other

### Reports

The system can generate:

* Weekly reports
* Monthly reports
* Total income
* Total expenses
* Net balance
* Spending by category

### Data Visualization

The frontend can display financial information using Chart.js.

Possible visualizations include:

* Income vs. expenses
* Expenses by category
* Monthly spending
* Balance trends

### Financial Analysis

The analytics component uses Pandas and NumPy to process financial data.

Possible analysis includes:

* Average spending
* Highest spending category
* Monthly spending trends
* Income-to-expense comparison
* Spending distribution

### CSV Export

Users can export their financial records into CSV format.

Pandas can be used to generate and process the exported data.

## 5. Non-Functional Requirements

The system should be:

* Easy to use
* Responsive
* Organized
* Maintainable
* Reliable
* Secure
* Efficient when processing financial records

## 6. Project Scope

### Included

* Authentication
* Financial CRUD operations
* Categories
* Reports
* Charts
* Data analysis
* CSV export
* Relational database

### Not Initially Included

* Bank account integration
* Real-time banking transactions
* Cryptocurrency tracking
* Automatic bank synchronization
* Investment management
* Payment processing

These features may be considered for future versions.

## 7. Success Criteria

The project will be considered successful when a user can:

1. Create an account.
2. Log into the system.
3. Add income and expenses.
4. Categorize transactions.
5. View their financial history.
6. View weekly or monthly reports.
7. Understand their spending through charts.
8. Analyze their financial data.
9. Export their transactions as CSV.
